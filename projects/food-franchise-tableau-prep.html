Food & Beverage Franchise Store Reporting Pack

Printable Tableau dashboards for monthly store reporting from 38 standardised Excel files.

SectorFood & Beverage Franchise
RoleData Analyst
EngagementProject engagement
ToolsTableau Prep, Tableau, Excel VBA, Hyper files

Context

A franchise group needed a monthly store reporting pack covering 38 stores. Each store submitted sales data in its own Excel file with inconsistent column names, sheet structures and date formats. The team wanted a single printable pack per store.

Business problem

Each store's Excel file was structured differently, so producing a standard monthly pack required manual rework each month. The franchise team could not benchmark stores against each other on a consistent basis.

Approach

The 38 source files stacked products and toppings together in rows, so an Excel VBA script generated row IDs to map each product to its toppings, and a wildcard union in Tableau Prep combined the files into one clean dataset. Built printable Tableau dashboards parameterised by store so the same template generated one pack per store every month, with LOD calculations keeping franchise-wide benchmarks correct even when filtered to one store, and Hyper extracts for fast month-end reload.

Modelling & preparation

One long-format fact table with store, product, topping, date and amount. Parameters for store and reporting period. LOD calculations for franchise-mean and topping-rank benchmarks. Hyper extract for fast reload at month-end.

Validation

Spot-checked five randomly chosen stores against their own raw Excel totals, confirmed YoY calculations against the prior-year archive, and asked the franchise operations lead to review three packs before bulk generation.

Stakeholder delivery & handover

Operations team trained on the month-end refresh: drop the 38 source files into a known folder, run the prep flow, the parameterised pack regenerates per store. Handover included a written runbook so the process didn't depend on any one person.

Outcomes

Each store now receives a consistent, printable monthly pack with the same KPIs, the same product and topping analysis, and the same YoY context. The franchise operations team can compare stores using the same yardstick.

Reflection

The prep flow was the real deliverable. Once 38 messy source files reliably became one clean dataset, the dashboard itself was the easy part, and the runbook meant the franchise team could keep using it after handover.
