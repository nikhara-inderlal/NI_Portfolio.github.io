Food & Beverage Franchise Store Reporting Pack

Thirty-eight Excel files per month, one per store, and a monthly review that was both slow and fragile. The fix was Tableau Prep, a touch of VBA, and printable Tableau packs the managers could read on paper.

The problem

Store-level reporting lived across 38 Excel files — one per store, mostly consistent but never quite identical. The monthly review meant collating, eyeballing and re-keying numbers, which made it both slow and easy to get wrong.

What I built

Standardised the 38-file input with Tableau Prep, plus a bit of Excel VBA for the inconsistencies Prep couldn't catch cleanly. On top of that, Tableau reporting packs sized to be printable — KPIs, product analysis, topping analysis and year-on-year comparisons — so managers could use them in the meeting or on the way to it.

Validation

Consistency across the file set was the main thing to validate. Same definitions, same calculations, same handling of edge cases — so a store-to-store comparison was actually comparing the same things.

What changed

The 38 files now feed a repeatable monthly process. The reporting pack replaces the spreadsheet collation step, and managers get a single document that's the same shape every month.
