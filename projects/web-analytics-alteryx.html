Problem
Multiple websites needed consolidated analysis without manual exports or per-site reconciliation from the Google Analytics interface.
Build
Built GA4 export to BigQuery with scheduled daily loads, combined DDL schema design, parameter unnesting, service-account ODBC access and SQL Server audit logging.
Result
Delivered a governed multi-site web analytics layer with refresh checks, key integrity checks and Power BI MoM/YoY variance reporting.

Business problem

GA4 export data is nested and inconsistent across sites. Sales and marketing needed consolidated analysis-ready tables, refresh confidence and variance reporting without rebuilding comparisons manually.

My role and ownership

Implemented the BigQuery-side schema approach, parameter unnesting and downstream curation pattern, then supported Power BI reporting using governed fact and dimension extracts.

What I built

Designed combined BigQuery schemas with DDL, surfaced nested event parameters as queryable columns, consolidated multiple websites, connected Alteryx through service-account JSON key and ODBC, and shaped curated outputs for Power BI.

Validation and reliability

Added SQL Server audit logging to validate freshness and key integrity on every run, making missing partitions, late-arriving rows and referential gaps visible instead of silent.

Outcome

The business gained a scheduled, consolidated multi-site web analytics layer with MoM/YoY variance views and explicit refresh reliability checks.
