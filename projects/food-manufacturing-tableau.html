Food Manufacturing & Distribution Performance Dashboard

Operations wanted one place to see how each site was tracking — expenses, forecast variance, throughput — and use it as the basis for the monthly review. Built in Tableau, with Alteryx doing the upstream prep.

The problem

Site-level operational performance was hard to compare. Expense, forecast variance and throughput were each living in different reports, which meant the monthly review meeting started with everyone reconstructing the same picture from scratch.

What I built

A Tableau dashboard with MTD/YTD actuals-versus-forecast, expense analysis and a dollar-per-tonne view, with Alteryx doing the upstream prep. The layout maps to how the operations team already structures the review — not how the data happens to be stored.

Validation

Calculations checked against source categories; visual structure validated against what the operations team expected to see in a review. Most of the iteration was on layout, not numbers — making sure the dashboard supported the existing meeting rhythm rather than fighting it.

What changed

The dashboard became the structure for the monthly performance review. The conversation now starts from the same view of variance and throughput, rather than from individual interpretations of separate reports.
