# Nikhara Inderlal Portfolio

Static GitHub Pages portfolio for Nikhara Inderlal, positioned for Sydney Analytics Engineer and BI Consultant roles.

## Structure

- `index.html` — homepage
- `about.html` — professional story and working style
- `projects.html` — Work gallery with filters
- `projects/` — detailed case study pages
- `skills.html` — skills grouped by capability
- `journey.html` — learning journey and Dashboard Week story
- `writing.html` — Data School blog/tutorial links
- `resume.html` — portfolio resume page
- `contact.html` — recruiter contact page
- `assets/img/projects/` — anonymised SVG dashboard mock-ups
- `assets/css/style.css` — custom responsive styling
- `assets/js/main.js` — mobile menu and project filter logic

## Publishing checklist

1. Review each project page and adjust wording to match what can be disclosed.
2. Replace any `Credential available on request` notes when exact public credential URLs are available.
3. Regenerate `sitemap.xml` when page paths change.
4. Re-check internal links and screenshots before pushing to GitHub Pages.

## Confidentiality

Dashboard images are mock-ups using anonymised/sample labels and data. They are intended to show structure, logic and design approach without exposing client data.


## Credentials included

Credentials are listed without placeholder outbound links unless an exact public verification URL is available.
