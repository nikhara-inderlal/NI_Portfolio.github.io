# Nikhara Inderlal Portfolio Rebuild

This is a clean static GitHub Pages rebuild of the previous portfolio website.

## Structure

- `index.html` — homepage
- `about.html` — professional story and working style
- `projects.html` — project gallery with filters
- `projects/` — detailed case study pages
- `skills.html` — skills grouped by capability
- `journey.html` — learning journey and Dashboard Week story
- `writing.html` — Data School blog/tutorial placeholders
- `resume.html` — portfolio resume page
- `contact.html` — contact placeholders
- `assets/img/projects/` — anonymised SVG dashboard mock-ups
- `assets/css/style.css` — custom responsive styling
- `assets/js/main.js` — mobile menu and project filter logic

## Before publishing

1. Replace placeholder contact details on `contact.html`.
2. Add exact LinkedIn, GitHub, Tableau Public and Data School blog URLs.
3. Add the final CV PDF to `assets/docs/` and update the resume button.
4. Embed the private/unlisted YouTube video on `index.html` once recorded.
5. Review each project page and adjust wording to match what can be disclosed.
6. Replace or refine mock dashboard SVGs if you want visuals that more closely match each project.

## Confidentiality

Dashboard images are mock-ups using anonymised/sample labels and data. They are intended to show structure, logic and design approach without exposing client data.
